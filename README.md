# Jochen2Canvas

Syncs Jochens deadlines and homework assignments to the canvas calendar
http://www.math.utk.edu/~denzler/M241-Fa2018/ClassDiary.html

## Archive status

This is an older Canvas automation demo. The web form and Python script now run
only as an offline parser demo; live Canvas login/API behavior is disabled.

## Offline demo

```bash
python3 hello.py
php -l process.php
```

`hello.py` parses `fixtures/jochen_diary.html` and prints planned calendar
items with `network_calls=0`.
